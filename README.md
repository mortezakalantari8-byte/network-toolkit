# ابزار شبکه (Network Toolkit)

یک اسکنر پورت شبکه ساده و سبک که با زبان پایتون نوشته شده است.

## امکانات
- اسکن پورت‌های رایج شبکه (21, 22, 23, 80, 443, 3389)
- سریع و ساده برای استفاده
- فقط با پایتون (نیازی به نصب کتابخانه اضافی نیست)
