# ابزار شبکه (Network Toolkit)

یک اسکنر پورت شبکه ساده و سبک که با زبان پایتون نوشته شده است.

## امکانات
- اسکن پورت‌های رایج شبکه (21, 22, 23, 80, 443, 3389)
- سریع و ساده برای استفاده
- فقط با پایتون (نیازی به نصب کتابخانه اضافی نیست)

## نحوه اجرا
۱. مطمئن شوید پایتون روی سیستم نصب است.
۲. اسکریپت را اجرا کنید: python Scanner.py
۳. آدرس IP هدف (مثلاً 127.0.0.1) را وارد کنید.

## شبیه‌سازی شبکه (Packet Tracer)
در پوشه packet-tracer می‌توانید فایل شبیه‌سازی شبکه (1.pkt) را پیدا کنید.
